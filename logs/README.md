# logs/

- **Work logs:** what an agent did in a larger task (date, what changed, why).
- **Backups:** before any risky change to a root file (e.g. `AGENTS.md`, `memory.md`, `MAP.md`), copy it here first, named like `memory-before-restructure-YYYY-MM-DD.md`.

This folder is skipped by hygiene checks and never loaded at session start.
