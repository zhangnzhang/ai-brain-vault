# inbox/

Drop anything new here: articles, screenshots, exported notes, rough ideas.

When you ask your agent to **"process the inbox"**, it will:

1. Read each item.
2. Distill it into a note with front matter (see `knowledge/sop/note-template.md`) in the right `knowledge/` subfolder — keeping numbers, percentages and links.
3. Register the note in `knowledge/_index.md` (and `MAP.md` if a new folder was created).
4. Move the original into `inbox/_processed/`.
